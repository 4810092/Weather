# City search field candidate 13 — local source boundary

Source: `c7f87e4bd9d16860507bf7331c592a3e60d3911c`. Prepared October 4, 2026.

The shared Android/iOS city search field now uses a compact rounded glass surface with an inline placeholder and a subtle focus outline. The floating label and its cut-out border are removed. Search and clear icons have consistent sizing and muted color; typed text retains normal contrast. A persistent localized accessible name remains present for empty and populated input, while the decorative placeholder is excluded from duplicate semantics. Existing query, clear, keyboard Search, navigation and saved-city behavior are retained.

The existing compact-height UI regression now checks the editor's accessible name before typing, after Search, and after clearing. Fresh `scripts/local-ci.sh android-ui` and `scripts/local-ci.sh full` passed (logs `/tmp/nimbo-search-field-ui.log` and `/tmp/nimbo-search-field-full.log`). The full gate covers 367 Python, 317 Kotlin, 51 instrumented Android UI and 37 Swift tests, lint, localization, migrations, Android bundles and unsigned iOS/watchOS Release builds. The Android matrix ran 17 UI tests each on API 24 phone, API 36 phone and API 36 tablet, including large Russian text, RTL, search and navigation. Light/dark, Russian 200% and tablet screenshots were inspected.

Fresh native iPhone 18 Pro and iPad Pro 13-inch M5 simulators (OS27) passed the visual review. On iPhone, Russian empty/focused/typed input kept the same shape and text alignment; real query results, clear, keyboard Search dismissal and cancel passed. Native accessibility exposed one search name plus the typed value. iPad empty/focused layout and cancel passed; its software keyboard did not appear during this pass, so no fresh iPad keyboard-input claim is made. Current cities (Fergana on iPhone and Samarkand on iPad), saved places and preferences were retained. Temporary Russian launch arguments were removed afterward. The generated app/widget were locally ad-hoc signed using existing App Group entitlements for simulator execution; this is not distribution signing.

Screenshots are in `build/simulator-ui-evidence/`: `search-field-iphone-empty.png`, `search-field-iphone-typing.png`, `search-field-ipad.png`, `search-field-android-light.png`, `search-field-android-dark.png`, `search-field-android-large-text.png` and `search-field-android-tablet.png`. Native checks used CUA AX controls; real VoiceOver/TalkBack speech was not captured. Manual Android UI access remains unavailable through the permitted tool; Android interaction evidence is the instrumented emulator matrix. The previous city-picker evidence in `growth/quality/release13-city-picker-source-sync-2026-10-04.md` applies to its earlier source only.
