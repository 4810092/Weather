# Security policy

Please report a suspected vulnerability privately through GitHub Security Advisories for this repository. Do not open a public issue containing credentials, exploit details, precise user location, signing material, or unpublished store configuration.

Include the affected commit/version, platform, impact, and a minimal reproduction when possible. The maintainer will acknowledge a complete report, assess severity, and coordinate a fix and disclosure timeline.

Only the latest released version and the current default branch receive security fixes. Never send production secrets as part of a report.
